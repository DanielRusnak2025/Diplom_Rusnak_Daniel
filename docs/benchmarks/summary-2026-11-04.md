# Benchmark summary — model and prompt selection (2026-11-03 … 2026-11-04)

Gold labels: `gold-2026-11-03.csv` (63 queue URLs, 37 articles / 26 non-articles, labelled by hand).
Scores count the whole pipeline: pre-filter decision + model answer. Category accuracy is computed only on
rows where both gold and pipeline say "article".

## Model selection (prompt v1, 2026-11-03 full run + 2026-11-04 run)

| Model | is_article | category | p50 latency | subtopic substituted |
|---|---|---|---|---|
| qwen3:8b | 89% (54/61) | **75% (27/36)** | 23 s | 2.4% |
| qwen3:14b | 62% (11-03 run, no pre-filter; qwen3:8b same run: 62%) | 70% (16/23; qwen3:8b same run: 79%) | 42 s | — |
| llama3.2 | 90% (55/61) | 38% (14/37) | 3.7 s | 48.8% |

Decision: **qwen3:8b** (llama3.2 is fast but unusable for categories; qwen3:14b is 2x slower and not better).

## Prompt / input iterations (qwen3:8b)

| Run | Change | is_article | category (all) | category (28 common) |
|---|---|---|---|---|
| v1 | title + meta description + body, pre-filter (root/404/short) | 89% | 75% | 21/28 |
| v2 | + non-article rules, IR/C&S boundary, "paywall = not article" | 74% | 82% (28 only) | 23/28 |
| v3 | − paywall line, + "paywall teaser is still an article", + URL line, + newsletter-host filter | 95% | 70% | 20/28 |
| v4 | + "URL sections don't decide category", + domestic-politics rule, + og:type filter | 95% | 59% | 17/28 |
| v5 | v3 prompt, **no URL line**, all pre-filters | 93% | 69% | 21/28 |

Pre-filter alone (v5): newsletter-host 12, not-found 5, og-type 3, root-url 1 — zero real articles skipped.

## Conclusions
- Pipeline-level is_article improved from 62% (first full run, no pre-filter) to 93–95%, mostly thanks to
  deterministic pre-filters, not prompt wording.
- Category accuracy for v1/v2/v3/v5 differs by 1–3 articles out of 28 — within sampling noise
  (SE ≈ 8 pp at n=28). Only v4 is clearly worse. Prompt tuning on this sample has reached its limit.
- Frozen configuration: **qwen3:8b, prompt v5, ai.include_url=false**.
- Known weak spots: Moldovan domestic politics → International Relations; IR vs Conflicts & Security boundary;
  section/topic pages without og:type (DW topic page, BBC topic page) and Spiegel "News des Tages" roundup.
