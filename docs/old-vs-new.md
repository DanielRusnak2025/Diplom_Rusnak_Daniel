# Сравнение: курсовая (JavaFX) → дипломная (Ktor + Android)

## Общее сравнение

| Аспект | Было (курсовая) | Стало (диплом) | Почему |
|--------|----------------|----------------|--------|
| **Интерфейс** | JavaFX десктоп-приложение (FXML, .css) | Android (Jetpack Compose) + Ktor REST API | Мобильный клиент практичнее; отделение клиента от сервера — стандартная архитектура |
| **Сборка** | Maven | Gradle Kotlin DSL, Kts-скрипты | Лучшая поддержка Kotlin, многомодульность, catalog зависимостей |
| **Язык** | Java 24 | Java 24 (`:core`) + Kotlin (`:server`, `:androidApp`) | Kotlin — современный стандарт Android; Java сохранена в core для переиспользования |
| **Веб-фреймворк** | — | Ktor 3.6.1 | Лёгкий, нативный Kotlin, отличная поддержка JWT и coroutines |
| **ИИ-классификация** | Простой один вызов Ollama; модель llama3.2; базовый промпт | Шестиуровневая таксономия тегов, промпт v5, ключевые слова, ArticleScorer, модель qwen3:8b | Улучшение точности; формализованная таксономия CATEGORY/SUBTOPIC позволяет строить персонализацию |
| **Персонализация** | Скор ≈ 50 (нейтральный) при нейтральной оценке | `smoothClamp` с затуханием у границ; лайк/дизлайк пропорционально весу тега | Нейтральная оценка больше не шумит; скор стабилизируется у границ ±100 |
| **Безопасность — сессии** | Нет сессий; только одна пользователь-форма | JWT (access 15 мин) + refresh с ротацией семейства; 403 при повторном использовании | Стандартная безопасная схема; защита от кражи токена |
| **Безопасность — пароли** | Пароли отображались в интерфейсе администратора | Пароли нигде не отображаются; Argon2-хэш; история паролей | Соответствие требованиям безопасности |
| **Безопасность — входа** | Нет защиты от брутфорса | LoginProtection: экспоненциальный backoff (1–60 с), 15-мин окно | Защита от подбора пароля |
| **Роли** | Поле `isAdmin` (булево) в таблице пользователя | `role` VARCHAR: `USER` / `MODERATOR` / `ADMIN`; миграция V4 | Три уровня доступа; модератор видит жалобы, но не управляет пользователями |
| **Администрирование — статьи** | Удаление статьи | Скрытие статьи (`hidden=true`) + сброс жалоб | Мягкое удаление сохраняет целостность данных и истории жалоб |
| **Администрирование — журнал** | Нет | `audit_log`: каждое административное действие фиксируется (кто, что, когда) | Аудит обязателен для дипломной работы; прозрачность действий |
| **Администрирование — фильтры** | Простой список без фильтров | Фильтры по дате, языку, региону, роли, наличию жалоб; cursor-пагинация | Удобство при большом объёме данных |
| **Транспорт** | Нет сети; всё локально | HTTPS с самоподписанным CA; Android доверяет только встроенному CA | Безопасное подключение через LAN/USB |
| **Пайплайн** | Пайплайн связан с JavaFX через Platform.runLater и статический синглтон | Пайплайн — отдельный `:core`, CLI-режим через HeadlessMain | Разделение ответственности; тестируемость |
| **Деплой** | Локальный запуск на Desktop | Сервер на ноутбуке, Android-приложение на телефоне/эмуляторе | Реальный клиент-серверный сценарий |

## Что осталось без изменений

- **Только локальный ИИ.** Ollama; никаких облачных вызовов.
- **Текст статьи не хранится.** Только метаданные и теги.
- **MySQL.** Та же СУБД; схема эволюционирует через Flyway.
- **Hibernate ORM.** Та же библиотека, теперь версия 7.x.
- **Gmail IMAP.** Тот же механизм получения писем.
