## Примечания

- Скриншоты Android снимать на эмуляторе (API 35+) или физическом устройстве
- Для диаграмм из Mermaid — использовать mermaid.live или встроенный рендерер VS Code/IntelliJ
- Размер иллюстраций для диплома — не менее 1200 px по ширине, формат PNG
- Сохранять в `docs/figures/` (каталог создать вручную перед сохранением)
